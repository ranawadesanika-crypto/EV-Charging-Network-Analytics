# EV Charging Network Analytics

An interactive EV charging analytics project built using MySQL, Excel, and Power BI to analyze charging demand, station performance, energy consumption, revenue, and vehicle usage patterns.

## 🛠️ Tools & Technologies

- Excel
- MySQL
- Power BI
- SQL
- ## 🎯 Project Objective

The objective of this project is to analyze electric vehicle charging data and identify patterns related to charging demand, station performance, energy consumption, revenue, and vehicle usage.

The analysis is presented through an interactive Power BI dashboard with multiple analytical views and filters.
